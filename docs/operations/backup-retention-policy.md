# Local backup retention

Run `python3 scripts/backup-retention-report.py` from the project root for a **read-only** inventory. The tool never decrypts configuration/database contents, deletes files, restores a database, changes credentials or starts services. It reports folder names, protection reasons and encrypted archive sizes only. Do not commit reports containing private paths or copy private configuration into Git.

Preserve the pre-Django baseline (`77bf229`, tag `checkpoint/pre-django-2026-10-18`), the latest three checkpoints whose manifests record a successful isolated restore, and the latest such checkpoint for each recorded table inventory. Preserve unknown/unverified items, standalone source patches/fingerprints and private-storage snapshots. The report checks encrypted-file SHA256 against the existing manifest; it does not rerun a database restore or independently authenticate the manifest. A table-name inventory is not a full schema fingerprint: column/constraint changes and unique source/configuration must be reviewed before pruning an apparently duplicate checkpoint. Candidates are review suggestions only, never deletion authorization.

Before any future cleanup, confirm the intended recovery boundary, inspect corresponding operation evidence and retain a recent independently restored database checkpoint plus required private objects/source/configuration. Restore into a new isolated database only; never restore a rehearsal over the source. Source-only UI changes need a small touched-file checkpoint, not another full Git bundle/database archive. Infrastructure/migration changes continue to require the existing encrypted checkpoint/verified-restore process.

Generated Next development caches can grow while the app serves routes. Keep the currently serving `.next-local-dev`; use the launcher to stop the frontend before any explicitly requested inactive-artifact cleanup. Never include `node_modules`, virtual environments or Next build caches in source checkpoints. No scheduled deletion or automatic retention is enabled by this phase.
