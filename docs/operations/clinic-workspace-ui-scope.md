# Clinic workspace UI implementation scope

Native, connected refinement requested October 20. Preserve existing clinical desk/Shadcn/Radix/Tailwind system, permissions, versioned clinical editor, immutable finance records, native queue ordering and all active workflows. Design variance 3, motion 2, density 5; task screens, not marketing surfaces. Minimal icons on patient profile.

1. Patient profile: identity/actions, exact native permission-scoped read summaries, quiet text tabs and saved SOAP/diagnosis/observation reader linked to the existing consultation editor, context/recent/appointment rail. No new patient status or independent notes persistence.
2. Read-only financial reporting: compare completed clinic-day windows (7/30/90) per permitted branch/currency; backend integer/Decimal money, independent current receivables snapshot, overdue/aging, method totals and daily net series. No accounting-profit/expense invention or payment integration.
3. Dashboard/Billing share that finance component; patient directory cards/table preference, consultation cards, appointment time/patient/status cards and queue ticket presentation retain native mutations/filters/pagination/confirmation.
4. Run new scoped reporting checks, production build/TS/scoped formatting/lint once; one combined desktop/tablet/phone browser pass and at most one focused confirmation for activation blockers. Log other findings; no broad repair loop.
5. Refresh relevant Graphify AST corpora, record sanitized Jev choices/limitations. Save source, stop app for fresh encrypted checkpoint/verified isolated restore and original fingerprints/storage checks, then activate the new artifact locally with ./medframe. No schema migrations required by this phase. No original fixture imports or credential/MFA changes.
