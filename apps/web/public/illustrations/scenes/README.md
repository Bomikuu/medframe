# Supplied waiting-room and Station scenes

Copied unchanged from the project owner's October 22 pack at
`medframe-illustrations-webp/webp`:

- `online-waiting-room.webp`: online appointment waiting at home.
- `station-pin-pairing.webp`: clinic device pairing.

These are transparent 600 × 430 raster WebP originals, not editable SVGs.
The separate editable SVG pack contains other scenes; no exact vector equivalent
for either of these originals was found. Do not claim CSS recolors these images.

Use the shared `MedframeScene` component. It preserves the whole illustration
with `object-contain`, uses Next Image optimization and reserves intrinsic image
space. Images are decorative; meaningful instructions, statuses and codes remain
native UI. The captions distinguish embedded example codes/queue information
from live clinic data. Original brand signatures and artwork are retained.
