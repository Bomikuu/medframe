# Station

Mode: Operate. Ordinary extension of Medframe's existing visual world.

Thesis: a clinic device should open directly into its assigned task while preserving named identity and clinical ownership.

Use the established palette, fonts, shared shadcn controls, generous touch targets and visible patient/save/connection context. Device table and pairing are task surfaces; clinician Station reuses the current real chart/editor. Public pairing has no patient context. Paired modes awaiting later phases show an honest setup state. No new brand tokens or raster assets are needed.

Phase 1 acceptance: paired approved clinician device, native sign-in, same saved consultation with restored chart selection, explicit acceptance, old writer blocked, lock/revocation and responsive code entry. Actual results will be recorded in `docs/operations/station-phase-1-verification.md`.
