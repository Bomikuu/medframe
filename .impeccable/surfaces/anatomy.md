# Anatomy workspace

Mode: Operate. Extend the existing clinical desk: cool canvas, white panels, navy actions and teal selection. The anatomy layer is a reference for clinician-entered facts, never a diagnosis or a calibrated patient model.

A searchable left structure navigator, generous central model, and right grouped finding form form one consultation workspace. Patient-side labels use canonical metadata. Expansion changes layout within the same form owner. On narrow screens panels stack, controls wrap and a useful viewport remains visible. Keyboard structure selection and a labelled 2D map remain available after WebGL/model failure. Empty, loading, unavailable, read-only and save-error states are explicit. Findings retain source/version, certainty and status. Only explicit selections appear in patient releases.
